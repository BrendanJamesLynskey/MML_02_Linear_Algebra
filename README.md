# Linear Algebra

Deck 02 of the [Mathematics for Machine Learning &mdash; Companion Series](https://github.com/BrendanJamesLynskey/MML_Hub).

**Live presentation:** https://brendanjameslynskey.github.io/MML_02_Linear_Algebra/

Systems of linear equations, matrices, Gaussian elimination, vector spaces,
basis &amp; rank, linear &amp; affine maps. The language every later chapter
uses, with an interactive Gaussian-elimination row-stepper that solves
$A\mathbf{x}=\mathbf{b}$ live.

## What's inside

- Three views of a system of linear equations &mdash; algebraic, row, column
- Matrices, matrix multiplication and the matrix inverse
- Gaussian elimination, reduced row-echelon form and the pivot picture
- Vector spaces and the eight axioms
- Linear combinations, span, linear independence
- Basis, dimension, coordinates and change of basis
- Rank and the four fundamental subspaces (range &amp; null space, on both sides)
- Linear maps as matrices once a basis is fixed
- Affine spaces and why ML usually uses one without saying so
- Interactive Gaussian-elimination stepper for a 3&times;3 system
